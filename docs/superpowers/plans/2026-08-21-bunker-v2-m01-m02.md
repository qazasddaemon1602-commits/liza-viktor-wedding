# Bunker V2 M01–M02 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Реализовать «Лишнего пассажира» и «Чёрный ящик» с реальными гостями, скрытыми свойствами, способностями и устойчивой уликой BK-17.

**Architecture:** Каждая миссия — V2 mission instance с серверными decisions и archive entitlements. Телефон выполняет персональные/вагонные действия, TV показывает агрегат, owner видит прогресс и fallback.

**Tech Stack:** PostgreSQL/Supabase + pgTAP, React/TypeScript, Vitest.

**Spec:** `docs/superpowers/specs/2026-08-21-bunker-connected-game-v2-design.md`

## Global Constraints

- Выполнять только после плана `2026-08-21-bunker-v2-contracts.md`.
- M01 не исключает реального гостя; `excluded` относится к персонажу.
- M02 имеет 300 s, три ответа, две обычные попытки и server-only answer key.
- Скрытая характеристика не приходит до M01 confirm.
- Ошибка M02 не блокирует будущий сюжет.
