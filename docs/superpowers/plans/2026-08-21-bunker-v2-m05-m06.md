# Bunker V2 M05–M06 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Реализовать необратимый маршрут с накопленными последствиями и общесоставной протокол, который гарантированно создаёт SECTOR-04 и 4719.

**Architecture:** M05 outcome детерминирован frozen scenario + текущим ledger/abilities. M06 собирает replaceable wagon votes в server consensus и создаёт глобальные final facts.

**Tech Stack:** Supabase/PostgreSQL, pgTAP, React/TypeScript, Vitest.

**Spec:** `docs/superpowers/specs/2026-08-21-bunker-connected-game-v2-design.md`

## Global Constraints

- Требует V2 contracts и M03 ledger; M06 использует M04 coordination outcome.
- M05 deadline 90 s; timeout выбирает B и фиксирует timeout.
- После открытия M05 никакого `random()`.
- M06 deadline 480 s, assistance +120 s, answer key never leaves server.
