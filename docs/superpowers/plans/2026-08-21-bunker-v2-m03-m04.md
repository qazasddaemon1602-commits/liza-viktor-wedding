# Bunker V2 M03–M04 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Реализовать атомарный аварийный запас, ситуационные способности, ограниченную межвагонную связь и безопасные обмены.

**Architecture:** Inventory остаётся ledger; M03 captain принимает только личные ability commitments. M04 использует frozen groups/operators, phased interaction и двухстороннюю transfer state machine.

**Tech Stack:** Supabase/PostgreSQL, pgTAP, React/TypeScript, Vitest.

**Spec:** `docs/superpowers/specs/2026-08-21-bunker-connected-game-v2-design.md`

## Global Constraints

- Требует завершённый V2 contracts package.
- M03: 360 s, пять проблем, максимум три закрытых problem slots.
- Captain не может применить чужую способность.
- M04: 300 s, сообщения ≤120 символов, server-side quota/rate limit.
- Любой расход/accept атомарен и не создаёт отрицательные quantities.
