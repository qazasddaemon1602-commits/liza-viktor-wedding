# Audio attribution

The train arrival, tournament gong and main Bunker cues use locally bundled acoustic recordings. UI micro-cues, the station chime and terminal key remain original deterministic project-owned synthesis. No cue is loaded from an external runtime URL; the quiet Web Audio oscillator remains only as an emergency decode/load fallback.
