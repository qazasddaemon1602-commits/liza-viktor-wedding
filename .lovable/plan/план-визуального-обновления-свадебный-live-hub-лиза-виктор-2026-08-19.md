# План визуального обновления: Свадебный Live-Hub (Лиза × Виктор)

Необходимо привести визуальный стиль приложения в соответствие с эстетикой «Editorial Wedding» (светло-бежевые тона, классическая типографика с засечками, тонкие линии, арки) и железнодорожной тематикой «Ritz-Carlton Railway» для билетов.

## 1. Цветовая палитра и типографика (index.css / globals.css)
- Обновить основные CSS-переменные:
  - Фон: `#F3EEE5` (Ivory/Paper)
  - Акценты: `#A58C5B` (Brass), `#9A6348` (Cinnamon)
  - Текст: `#252724` (Graphite)
- Настроить шрифты:
  - Заголовки: Georgia или "Times New Roman" (serif) с отрицательным letter-spacing
  - Текст и мета-данные: системный sans-serif (Inter) с увеличенным letter-spacing для меток (caps)

## 2. Обновление страницы регистрации (/join)
- Изменить текст приветствия:
  - С «ПОЕЗД ВИКТОРА» на «ALEXANDRA & MICHAEL» (адаптировано под Лизу и Виктора)
  - Добавить подзаголовок с датой «SEPTEMBER 20, 2025» (обновить на 30.08.2026)
- Стилизовать форму регистрации:
  - Использовать минималистичные поля ввода с нижней границей
  - Добавить декоративные элементы (звездочки, тонкие разделители)
- Обновить «виртуальный билет»:
  - Добавить текстуру бумаги (легкий шум или паттерн)
  - Реализовать стиль «билетного корешка» с перфорацией (dashed line)
  - Использовать железнодорожную графику (локомотив, штампы)

## 3. Обновление главного экрана (/screen)
- Улучшить Idle-состояние:
  - Сделать QR-код центральным элементом в «раме»
  - Добавить фоновые «арочные» формы (SVG или CSS)
  - Внедрить плавные анимации появления и «дрейфа» фоновых элементов

## 4. Графические ассеты (SVG)
- Обновить `WeddingRailwayEmblem.tsx` для соответствия стилю Ritz-Carlton Railway (более детализированный локомотив в стиле гравюры)
- Создать новые иконки для разделов (кольца, бокалы, торт) в стиле тонких линий

## Технические детали
- **Безопасность**: Не менять Supabase RPC, RLS или бизнес-логику регистрации/вагонов.
- **Анимации**: Использовать `framer-motion` для плавных переходов между состояниями (регистрация -> билет).
- **Адаптивность**: Сохранить mobile-first подход для `/join` и 16:9/4K для `/screen`.
- **Z-index**: Сохранить приоритет Bunker emergency (1000+).
